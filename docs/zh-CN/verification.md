  均已停止，临时 home 均已删除。

的页面错误。首轮 harness 失败暴露同名控件定位与插件初始化等待问题，修正后完成上述
通过记录，同时验证了失败截图、trace 和日志收集。这是冒烟覆盖，不代表完整视觉、
无障碍、移动端或 provider 验证。

归档回归先复现了消失子 Agent 的旧历史被误用，以及临时枚举失败被永久缓存的问题。
修复后，任何已观察的子 Agent 从当前清单消失，都在刷新与重启后保持未知，包括旧记录
及此前读到精确时间、上界或空历史的情况。仍在清单且本轮确认空历史的子 Agent 保留
原允许行为。真实 `PaseoHost` 与 `Workboard` 配合 API 替身，覆盖子 Agent 新消息
紧接移除，再以全新宿主实例和 Store 重启；同时验证连续失败中的 60 秒重试边界、
枚举恢复后归档成功，以及父 Agent 归档但活动时间不变的情况。四项原始复审探针均通过，
恢复探针同步推进宿主重试时钟。删除了无用的子 Agent 门禁字段，以及允许凭移除前
旧历史放行归档的测试。

v6 迁移回归也复现了已观察的子 Agent 没有消息时间时提前归档的问题。运行真实 v6（`e179cf7`）
宿主与 Workboard 的探针还证明，枚举失败后可能保留缓存子 Agent，却将
`seenWhileLive` 改为 false。迁移现在根据 provider 子 Agent ID 保留这些记录，
并验证升级、刷新及重启后仍阻止归档；未观察过的普通占位 ID 继续清理。

新增缓存回归复现了订阅恢复或请求失败后继续复用完整旧清单，以及在途旧结果重新被视为
完整的问题。**11 个新增回归场景**在修复前全部失败，修复后通过，覆盖事件丢失期间出现
新子 Agent、重新枚举失败时保留已观察的子 Agent、60 秒重试边界、枚举请求在途时失效，
以及多父 Agent 遍历期间失效。已归档父 Agent 用例还验证订阅恢复后保留子 Agent。
三项新增独立复审探针及此前五项归档/迁移探针均在本地通过。普通连接断开通过恢复后的
snapshot 路径覆盖；订阅请求失败走独立的 error 回调。以上用例使用真实宿主和看板类
配合 API 替身，不代表实际网络断连测试。

该本地版本尚未在 GitHub 运行，Ubuntu/Windows CI 执行结果仍未验证。本轮没有 push、

`/tmp/workboard-list-g8eWnC`，通过 Chrome 实际检查了新增列表视图。开启

真实界面检查发现，折叠或排序后浏览器的 `onLayout.y` 可能保留旧值。拖动几何现根据当前分组及任务顺序和实测高度重建位置。新增两项交互回归：使用旧实现时失败，修复后通过，分别覆盖折叠改变分组位置、排序改变任务行位置且未触发仅位置变化的 layout 事件。

其它隔离本地 home 可用以下命令开启 daemon 自带的 Web UI，并重启选中的 daemon：

```sh
paseo daemon config set features.webUi.enabled true --home /path/to/test-home
paseo daemon restart --home /path/to/test-home
```

若选中的 daemon 尚未运行，改用
`paseo daemon start --home /path/to/test-home`，然后在本机浏览器打开其配置的 HTTP 地址。新增列表视图尚未实际验收长时间边缘自动滚动、拖动途中的 `Escape` 或失焦、原生移动端客户端和 Electron。
